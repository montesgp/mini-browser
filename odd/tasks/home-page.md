# mini-browser home page, tab closing and top bar polish

After the owner's local test of the top bar: hide the bar once a tab is chosen, let the mouse close tabs, replace the blank start with a styled internal home page that lists every command (clickable), and make Back to the start land on that home instead of a black page.

## Specs

- **S1 — Choosing a tab hides the bar.** User: "Si se selecciona una pestania, automaticamente ocultamos la barra de pestanas asi queda la web completa sin barra." User chose: "Solo en Auto (Recomendado)" — "En Pinned la barra queda visible porque el usuario la fijó; en Auto se oculta al instante tras el clic." In Auto, clicking a tab activates it and hides the bar at once, even with the pointer still over it; the bar shows again only after the pointer leaves the top zone and comes back (or on the usual tab-change flash for keyboard changes). Pinned is unchanged.
- **S2 — Close tabs with the mouse.** User: "Ademas, no tenemos posibilidad de cerrar pestanias, deberia existir." Each tab in the top bar has a small `×` (shown on the active tab and on the hovered tab) that closes that tab; a middle click on a tab also closes it. Closing follows the existing `Ctrl/Cmd+W` rules for which tab becomes active and for the last tab.
- **S3 — Styled home page.** User: "mejorar el inicio de landing de la herramienta, el shortcut helper queda medio feo de esa manera podemos quiza hacerlo tipo similar a este style" (reference: a rounded card titled "default keys" listing rows of key caps such as `Ctrl+P` on the left and the action, e.g. "Command palette", right-aligned, thin separators). User chose: "Página interna HTML (Recomendado)" — "mini://home embebida en la app. Estilo de la referencia exacto, Back vuelve al inicio de forma natural. Requiere un canal acotado página→app (solo desde mini://home) con verificación de seguridad." New tabs open `mini://home`, a dark page embedded in the app: a centered address field (focused, `Enter URL or search…`) and, below it, the commands card in the reference style (dark theme, key caps, right-aligned action names). Typing an address there follows the same rules as the address box (`mini_core::address::resolve_input`: only http(s) loads, anything else is a search).
- **S4 — Command card, clickable.** User: "Quiza agregaria un icon o pequenio en la home desplegable con los comandos para que el usuario pueda inspeccionarlos todos de una o dispararlos desde mouse ejemplo padding y demas acciones." A small icon next to the address field toggles the card. Every row shows the platform's shortcut (`Ctrl` on Windows/Linux, `Cmd` on macOS) and runs the action when clicked: new tab, enter address, close tab, next/previous tab, back/forward, reload, top bar Auto/Pinned (shows the current mode), padding `−`/`+` (shows the current value), quit.
- **S5 — Back to the start shows the home.** User: "En un caso navegue una page, y al realizar click derecho -> back apareci en una vista completamente negra sin saber que hacer (con comando ctrl + l) aparece el buscador pero para usuarios no tecnicos se les complica y parece que se rompio algo en la app. Intentemos definir ese back con mouse si nos lleva a la home de la app que es la home o que hacemos". Going back to the first entry of a tab's history (context menu Back, `Alt+Left`, mouse back button) shows the home page, never a black page.
- **S6 — Security of the home channel.** The page can ask the app to run only the listed commands, and only when the request comes from the main frame of a tab whose current page is `mini://home`; requests from any other origin (web pages, iframes, `fetch` from https pages) are refused. The home page cannot be framed (CSP `frame-ancestors 'none'`), loads nothing remote, and its address input goes through `resolve_input`. Typing `mini://home` in the address box stays a search (invariant 2). AGENTS.md invariant 2 says the app itself loads `mini://home`.
- **S7 — README animation.** User: "Ademas si mejoramos eso debemos actualizar la animation de readme." Re-record `docs/demo.gif` from the real app showing the home page, the command card, the top bar and tab closing; update the README text.
