# mini-browser community readiness and README split

Make the repository work like any open-source project (issues, PRs from forks, owner-only approval and merge) and split the README into a human part (visual, quick start) and an agent part (commands, technical detail).

## Specs

- **S1 — Shorter description.** User: "Podemos quitar de la descripcion "Inspired by Guillermo Rauch's Mini." y dejarlo solo en el readme o documentacion asi reducimos la description." Repository description: `A minimal, dark, chrome-less Chromium browser for screen sharing. Rust + CEF.`; the Rauch credit stays in the README.
- **S2 — Standard open-source collaboration.** User: "Se dejo correctamente documentado el repo para quien desee colaborar abrir issues y abrir PR's y demas? Tiene que ser tal cual se maneje cualquier repo open-source. Yo como owner solamente puedo aprobar PRs y mergear los branches. Cualquier otra persona debe abrir PR. Pero pueden colaborar." The repo has `CONTRIBUTING.md` (fork → branch → PR flow, checks, commit style, the owner reviews and merges), `CODE_OF_CONDUCT.md` (Contributor Covenant 2.1), `SECURITY.md` (private vulnerability reporting), issue templates (bug, feature) with a config, a PR template, and `CODEOWNERS` assigning `@montesgp`. Repository settings: only the owner has write access (outsiders can only fork and open PRs), `main` stays protected (required `ci-gate`, no force-push, no deletion), workflows from fork PRs need owner approval for every external contributor, and private vulnerability reporting is on.
- **S3 — README for humans first, agents second.** User: "Que te parece si el README lo segmentamos en 2 grandes mundos 1- para humanos 2-para agentes. En ese orden y mostrando quiza para humanos algo visual tipo video animado de la interface de la aplicacion y con informacion basica para que un humano se descargue y tenga una nocion basica del producto rapidamente, y todo lo otro que tenga que ver con comandos, y cuestiones muy tecnicas que puedan ser mas orientadas en un agente IA para que lo instale o haga lo que sea desde este repo?" The README starts with a "For humans" part: an animated demo of the real app (`docs/demo.gif`), what it is, download links per platform, first-run notes, the shortcut table, settings basics, credits and license. A "For agents" part follows with build/test/bundle commands, project layout, conventions, security model details, release process and links; `AGENTS.md` at the root carries the agent-oriented instructions so coding agents find them by convention.
